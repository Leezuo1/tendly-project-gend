# Platform identification assets

These local SVG assets identify third-party services in the mock connection flow.

- `messenger.svg`: [Facebook Messenger logo 2020](https://commons.wikimedia.org/wiki/File:Facebook_Messenger_logo_2020.svg), sourced by Commons from Facebook's brand assets. Uses the gradient version requested for this interface.
- `zalo.svg`: [Icon of Zalo](https://commons.wikimedia.org/wiki/File:Icon_of_Zalo.svg).
- `tiktok.svg`: [TikTok icon, SVG Logos](https://github.com/gilbarbara/logos/blob/main/logos/tiktok-icon.svg), multicolor version.
- `shopee.svg`: [Shopee](https://commons.wikimedia.org/wiki/File:Shopee.svg). ViewBox cropped to the shopping bag symbol; original paths and colors retained.

Source pages retain their respective attribution and licensing information. The Website / Excel symbol is a generic interface icon, not a third-party logo.
